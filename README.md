# Lukkar Veículos · site

Site estático (HTML, CSS e JS em um único `index.html`). Sem build.

## Editar dados
No fim do `index.html`, edite:
- `LOJA` (WhatsApp, endereço, horário, redes)
- `ESTOQUE` (carros reais; remova `exemplo:true` dos itens que forem reais e apague os de exemplo)

## Publicar na Vercel
Import Git Repository, Framework Preset **Other**, sem build command, output na raiz.

Prompt do assistente (para uma futura versão com IA): `docs/Lukkarzinho_prompt.md`.
